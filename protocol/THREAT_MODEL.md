# V2 threat model

Assume adversarial parties, evidence, RPC/indexer data, transaction ordering, and offchain messages. Trust boundaries are the deployed V2 graph, governance bootstrap/configuration, oracle assumptions, standard AZL transfer semantics, fixed-route intake executor, and curated bonded panel. Safety and liveness controls are summarized in [attack surface](../docs/ATTACK_SURFACE.md), [failure modes](../docs/FAILURE_MODES.md), and [griefing resistance](../docs/GRIEFING_RESISTANCE.md).
