# V2 architecture

AZZLE V2 separates lifecycle (TaskRegistryV2), job custody (EscrowVaultV2), collateral custody (AgentDepositVaultV2), pricing/oracles, intake, scope, arbitration/bonds, reputation, treasury, and staking. All value-bearing protocol liabilities are AZL. See [README](../README.md) for the component map and each linked canonical specification for behavior.
