# V2 arbitration

AZZLE V2 uses a prospectively curated panel with AZL bonds and deterministic round-robin assignment. It does not use party-selected arbitrators, reputation tiers, or multi-tier escalation.

- Flow and deadlines: [`DISPUTE_FLOW.md`](DISPUTE_FLOW.md)
- Bond mechanics: [`VERIFIER_SPEC.md`](VERIFIER_SPEC.md)
- Contract: [`contracts/src/v2/ArbitrationModuleV2.sol`](../contracts/src/v2/ArbitrationModuleV2.sol)

Historical V1 arbitration is archived under [`docs/legacy-v1/`](../docs/legacy-v1/).
