# Legacy V1 documentation

This area is historical and non-normative. AZZLE V2 integrations must use [the root documentation](../../README.md), [V2 Solidity](../../contracts/src/v2/), and the [V2 deployment manifest](../../contracts/deployments/base-8453.json).

Removed V1 concepts include USDC task escrow, fixed token fees, direct hire, milestone/stream/hour-block modes, proof-review states, pause/delete recovery, party-selected and tiered arbitration, weighted signal enums, and the V1 subgraph. Do not use V1 addresses, ABIs, methods, or state for V2 transactions.
